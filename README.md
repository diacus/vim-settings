# Personal and Portable Vim Settings

A plugin with the core set of options I apply on every machine, the
base layer of a small family of focused plugins. It sets up the editor
behavior itself, the file explorer, and a handful of mappings for
buffer navigation and for writing pairs of brackets and quotes. It can
also adapt Vim to the Spanish and Latin American keyboard layouts.

## The plugin family

| Plugin | What it adds |
|---|---|
| **vim-settings** | this plugin: core options, netrw, wildignore, mappings |
| [vim-development](https://github.com/diacus/vim-development) | source code settings, breakpoints, tags, quickfix helpers |
| [vim-markdown](https://github.com/diacus/vim-markdown) | markdown headings, folding, pandoc preview |
| [vim-spelling](https://github.com/diacus/vim-spelling) | spell checking and suggestion mappings |
| [vim-gvimsettings](https://github.com/diacus/vim-gvimsettings) | settings that only make sense in GVim |

## Features

- Sane defaults: `utf-8`, no `vi` compatibility, 24 bits of color
  where available, `hidden` buffers, system clipboard, wildmenu, and
  `splitbelow`/`splitright` window placement.
- Transparent background, so the terminal emulator's translucent or
  pictured background shows through.
- File explorer (netrw) configured: no help banner, dotfiles hidden by
  default, files opened with the file manager of the operating system
  (xdg-open on Linux, open on MacOS).
- File completion ignores the files generated by compilers,
  interpreters and version control systems (`wildignore`).
- Buffer navigation with the arrow keys: `<Up>` lists the loaded
  buffers, `<Left>` and `<Right>` jump to the previous and next buffer.
- Insert-mode mappings that open pairs of braces, brackets, quotes and
  parenthesis, placing the cursor inside them.
- Airline status bar (if installed) with powerline fonts and custom
  separators and symbols.
- Optional keyboard layout adaptation for `es` and `latam` layouts,
  with `,` and `¿` leaders.
- Text justification through Vim's own `macros/justify.vim` macro,
  when present, providing the `:Justify` command.

## Settings chosen

| Option | Value | Why |
|---|---|---|
| `nocompatible` | on | Vim, not `vi` |
| `nowrap` | on | long lines stay on their gutter column |
| `termguicolors` | on | true colors in modern terminals |
| `clipboard` | `unnamed` | yank goes to the system clipboard |
| `fillchars` | `vert:\ ` | plain vertical split separators |
| `encoding` | `utf-8` | |
| `grepprg` | `grep -nH $*` | grep shows file and line numbers |
| `hidden` | on | buffers don't force saving when switching |
| `list`, `listchars` | `tab:▸\ ,trail:·` | visible tabs and trailing spaces |
| `mouse` | `a` | full mouse support |
| `numberwidth` | 6 | fixed line number column width |
| `path` | `+=**` | search files recursively |
| `ruler` | on | cursor position on the last line |
| `t_Co` | 256 | legacy 256 color default |
| `wildmenu` | on | enhanced command line completion |
| `cmdheight` | 2 | taller command line |
| `splitbelow`, `splitright` | on | new windows below and right |
| `textwidth` | 80 | default document margin |
| `guioptions` | — | set by [vim-gvimsettings](https://github.com/diacus/vim-gvimsettings) in the GUI |

## Global variables

| Variable | Values | Effect |
|---|---|---|
| `g:kb_layout` | `'es'`, `'latam'` | applies the Spanish or Latin American layout mappings on load; anything else keeps the English defaults |
| `g:netrw_style` | `'tree'` | netrw shows directory trees in a 20% side window |
|  | `'full'` | netrw long listing in the current window |

## Installation

1. Run the installer script, the script will install vim-plug and a `~/.vimrc` boilerplate:

```shell
curl -o- https://raw.githubusercontent.com/diacus/vim-settings/main/scripts/install.sh | bash
```

2. Edit the downloaded `~/.vimrc` as you want — uncomment the plugins
   you use, set `g:kb_layout` and `g:netrw_style` if you want them

3. Run `:PlugInstall` inside vim

4. Restart vim to see all the settings applied

## Getting help

Once installed, you can see the documentation within the vim's help
system:

```vim
:help settings.vim
```
