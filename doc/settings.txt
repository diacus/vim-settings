              Personal and portable Vim settings          by @diacus

This plugin provides the core set of options the author uses on every
machine.  It is meant to be the base layer of a plugin family; it defines
a handful of mappings of buffer navigation and of pairs of brackets and
quotes, and it can adapt the keyboard to the Spanish and Latin American
layouts.  Optional pieces of the old monolithic configuration live on
their own plugins: |vim-spelling|, |vim-development|, |vim-markdown| and
|gvimsettings.vim|.

BOOTSTRAP                                          *settings-bootstrap*

The repository ships an installer that sets up a fresh machine:

>
    curl -o- https://raw.githubusercontent.com/diacus/vim-settings/main/scripts/install.sh | bash
<

The installer downloads vim-plug to ~/.vim/autoload/plug.vim and
~/.vimrc, a small boilerplate based on scripts/main.vim.  The boilerplate
defines |<Leader>| as <Space>, plugs this and the sibling plugins, and
applies the colorscheme "nord", tinting the vertical split line
|VertSplit| when it is loaded.

OPTIONS                                                *settings-options*

This plugin turns on 'syntax' highlighting and the filetype mechanism >
    syntax on
    filetype plugin indent on
    filetype plugin on
<
and applies the following core options:

'nocompatible'  Vim, not vi, behavior.

'nowrap'        Do not wrap long lines.

'termguicolors' Use 24-bit color when the terminal supports it.

'clipboard'     Use the system clipboard as the unnamed register >
    set clipboard=unnamed
<

'fillchars'     Plain vertical split separators: >
    set fillchars=vert:\
<

'encoding'      Set to "utf-8".

'grepprg'       Show the filename and line number when grepping: >
    set grepprg=grep\ -nH\ $*
<

'hidden'        Do not force saving a buffer when switching to another.

'list'          Display unprintable characters as: >
    set listchars=tab:▸\ ,trail:·
<

'mouse'         Full mouse support >
    set mouse=a
<

'numberwidth'   Fixed column width for the line number column: >
    set numberwidth=6
<

'path'          Search files under the current directory recursively: >
    set path+=**
<

'ruler'         Show the cursor position on the last line.

't_Co'          Use 256 colors >
    set t_Co=256
<
                Note: newer Vim and Neovim detect this on their own.

'wildmenu'      Enhanced command-line completion.

'splitbelow'
'splitright'    New windows are created below and to the right of the
                current one.

'textwidth'     Default document margin: >
    set textwidth=80
<

'cmdheight'     Two lines for the command line. >

    set cmdheight=2
<

WILDIGNORE                                          *settings-wildignore*

Completion, |wildmenu| and file expansion ignore the files generated by
compilers, interpreters and version control systems.  The patterns put
in 'wildignore' are:

 __pycache__/**    Compiled Python packages
 .*.pyc            Python bytecode
 .*.o              Object files
 .*.swp            Vim swap files
 .*~               Backup files
 .git              Git repositories
 .DS_Store         MacOS Finder metadata
 **/node_modules/**  Node.js packages
 tags              Tags files

Add your own patterns with :set: >

    set wildignore+=*.aifc
<

TRANSPARENCY                                    *settings-transparency*

In the terminal, the background is transparent, which suits terminal
emulators with a translucent or picture background: >

    hi Normal guibg=NONE ctermbg=NONE
<
In the GUI this is deliberately skipped: `NONE` means the default white
background there, so the colorscheme keeps painting its own background.

AIRLINE                                                  *settings-airline*

When |vim-airline| is installed (detected through |:AirlineRefresh|),
this plugin enables the powerline fonts, sets the separators and a few
symbols, and formats the tabline with the "unique_tail" formatter.

JUSTIFY                                                  *settings-justify*

Vim ships a macro to justify text.  When the macros/justify.vim file is
present in your runtime path, it is loaded, and the |:Justify| command
becomes available.

VARIABLES                                            *settings-variables*

*g:kb_layout*  When set to 'es' or 'latam', the keyboard mappings of
             |settings-keyboard| are applied, the first time this plugin
             loads.  Any other value, or leaving it unset, keeps the
             mappings of the English layout.  The layout can be changed
             at runtime too, see |settings-commands|.

*g:netrw_style*  With the value 'tree', the file explorer |netrw| shows
             the directories as trees in a 20% side window, and opens
             the files in the previous window: >
    :let g:netrw_style = 'tree'
<
             Use the value 'full' to show the long listing of netrw in
             the current window: >
    :let g:netrw_style = 'full'
<
             When the variable is not set, netrw keeps its default thin
             listing in the current window, see |settings-netrw|.

NORMAL MODE MAPPINGS                        *settings-normal-mappings*

<Up>        Shows the list of loaded buffers, |:ls|, and completes the
            name of the buffer to open.

<Left>      Jumps to the previous buffer, |:bprevious|

<Right>     Jumps to the next buffer, |:bnext|

<Down>      Disabled in normal mode.

Note: the rest of the mappings, the <F2> spell checking and the
<Leader> prefixed ones, belong to the sibling plugins, see
|vim-spelling| and |vim-development|.

INSERT MODE MAPPINGS                         *settings-insert-mappings*

These mappings open a pair of braces, brackets or quotes when a new
line is required, and leave the cursor inside them, or they insert the
pair around the cursor:

{<CR>        Inserts a code block >
    {
      ...your code goes here...
    }
<
[<CR>        Inserts a multi line array >
    [
      ...your code goes here...
    ]
<
(<CR>        Inserts a multi line tuple >
    (
      ...your code goes here...
    )
<
''           Inserts a single quoted string, placing the cursor inside

""           Inserts a double quoted string, placing the cursor inside

((           Inserts a pair of matching parenthesis, placing the cursor
             inside them

[[           Inserts a pair of matching square brackets, placing the
             cursor inside them

{{           Inserts a pair of matching curly brackets, placing the
             cursor inside them

<Tab><Tab>   Leaves the insert mode, jumps to the end of the next
             blank-separated word, see |WORD|, and goes back to insert
             mode.

             Note: while spell checking is enabled, see |vim-spelling|,
             <Tab> shows the spelling suggestions instead.

COMMANDS                                              *settings-commands*

                                                            *:KbEs*
:KbEs        Switches the mappings to the Spanish keyboard layout,
             see |settings-keyboard|

                                                            *:KbLatam*
:KbLatam     Switches the mappings to the Latin American keyboard layout

NETRW                                                      *settings-netrw*

The file explorer, |netrw|, is configured to hide its own help banner,
'g:netrw_banner', and to open the files with the file manager tool of
the operating system, 'g:netrw_browsex_viewer': xdg-open on Linux, and
open on MacOS.  On Windows, netrw picks its own viewer.

The dotfiles are hidden by default.  To show them: >

    :let g:netrw_hide = 0
<

Also, each |netrw| buffer is wiped out as soon as you leave it,
'bufhidden' set to delete, otherwise Vim may hang on |:q| with old
explorer buffers in the background.

The listing style is selected with |g:netrw_style|.

KEYBOARD                                                *settings-keyboard*

When |g:kb_layout| is 'es' or 'latam', this plugin maps the keys that
are hard to reach in the Spanish and Latin American layouts:

- The <Space> key is mapped to the search, /, in normal and visual
  mode, because the slash is hard to reach in those layouts.

- ñ and Ñ, the keys in the same place of the semicolon, start the
  command mode, :, in normal and visual mode.

- In the Spanish layout, es, the leader key is the comma, ",", because
  it is easier to reach than the backslash; and ¡ works as <Esc>, and
  ç jumps to the tags, like <C-]>.

- In the Latin American layout, latam, the leader key is the open
  question mark, "¿"; and { and } jump between tags, like [ and ].

Additionally, Spanish is added to 'spelllang', since the layout is in
Spanish too.

The layout can be changed at runtime with the commands |:KbEs| and
|:KbLatam|.  The English layouts keep the original keys, so they need
no mappings and no command.
